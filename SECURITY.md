# Security policy

## Supported versions

Security fixes target the latest published 0.1.x release. If you use an older version, you may
need to upgrade to receive a fix. There is no long-term support commitment or guaranteed response
time for the beta.

## Reporting a vulnerability

Report vulnerabilities through
[GitHub's private reporting form](https://github.com/nickyua/justflow/security/advisories/new).
Please do not post vulnerability details in a public issue. If private reporting is unavailable,
open an issue asking us to enable it, without including technical details of the vulnerability.

Include the affected version, what could go wrong, and a small example that reproduces the problem.
If you use a container, include its image digest. Use test data and remove real credentials or
customer information. A suggested fix is welcome but not required.

We'll work with you on a fix and agree on when to share the details publicly. Let us know if
you would like credit in the release notes.
