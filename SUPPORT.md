# Support

For questions and bug reports, open a [GitHub issue](https://github.com/nickyua/justflow/issues).
Justflow 0.1 is a community-supported beta. Responses are best-effort; there is no guaranteed
response time.

For a bug report, include your Justflow and Python versions, how you run the application
(locally, in Docker, or on AWS), the error code, and a small example that reproduces the problem.
Remove credentials, customer data, and private addresses from anything you share. Full Temporal
histories can contain application data, so avoid attaching them to public issues.

Report security problems privately using [SECURITY.md](SECURITY.md).
See the [support guide](docs/support.md) for upgrade issues and release details.
